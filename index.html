Paso 1

Pega este prompt en Claude Code

Este único prompt construye la habilidad de YouTube, instala NotebookLM-PY y conecta todo. No necesitas otros archivos.

Prompt de configuración → Claude Code 
Quiero configurar un pipeline de investigación automatizado
conectando Claude Code con NotebookLM. Realiza estos pasos
y yo aceptaré ('accept') todos los cambios propuestos:

1. Crear habilidad de investigación en YouTube:
Crea un skill personalizado en Python usando la dependencia
yt-dlp. Debe poder buscar metadatos de YouTube: títulos,
vistas, autor, duración y URLs a partir de una consulta.

2. Integrar NotebookLM-PY:
Quiero usar la API no oficial de NotebookLM creada por
Teng Lin. El repositorio está aquí:
https://github.com/teng-lin/notebooklm-py
Instala los paquetes necesarios y crea un skill que permita:
 • Crear nuevos notebooks
 • Subir URLs de YouTube como fuentes
 • Solicitar análisis y entregables como infografías,
   presentaciones y tarjetas de estudio

3. Guiarme en la autenticación:
Una vez instaladas las herramientas, recuérdame abrir una
ventana de terminal separada para ejecutar el comando de
login de notebooklm y autenticarme con mi cuenta de Google.

4. Confirmar que todo está listo:
Cuando todo esté instalado y los skills sean reconocidos,
avísame de que estás listo para una prueba.

El objetivo es que, una vez terminado, pueda darte un
comando como este:

"Usa el skill yt-research para encontrar los 25 vídeos
más recientes sobre [TU TEMA]. Una vez que tengamos esos
vídeos, envíalos a NotebookLM usando el skill notebooklm.
Dame su análisis de los hallazgos principales y luego haz
que NotebookLM cree una infografía estilo pizarra."

Importante: Si te doy el comando de investigación sin
especificar tema, pregúntame qué quiero investigar.
Qué pasa después

Acepta, autentícate, investiga

Claude Code hace el trabajo pesado. Tú solo sigues estos 4 pasos.

1

Di que sí a todo

Claude Code empieza a escribir scripts de Python y crear los skills. Cuando pida permiso para ejecutar comandos o instalar paquetes, pulsa Y o Enter. Si no tienes Python instalado, Claude Code se encarga también.

2

El paso de login — lee esto bien

Cuando Claude te diga que es hora de autenticarte, abre una terminal completamente nueva (no la de Claude Code) y ejecuta:

notebooklm login

Se abrirá un navegador — inicia sesión con tu cuenta de Google. Cierra esa terminal y vuelve a Claude Code.

3

Claude confirma que está listo

Verás un mensaje confirmando que los skills están instalados y reconocidos. Te preguntará qué tema quieres investigar.

4

Lanza tu primera investigación

Usa el comando de abajo. Claude busca en YouTube, envía los vídeos a NotebookLM y genera tu infografía.

Preguntas frecuentes

Todo lo que querías
saber antes de empezar

Respuestas claras a las dudas más habituales.

¿Necesito saber programar?
No. Claude Code hace todo el trabajo técnico por ti. Tú solo pegas el prompt que te damos, aceptas los permisos que te pida y ya está listo en menos de 10 minutos.
¿Por qué tiene que ser Claude Pro y no el gratuito?
El plan gratuito de Claude no soporta skills personalizados, que es lo que hace que este sistema funcione. Con el plan Pro ($20/mes) puedes usar este sistema y cientos más.
El navegador no se abre al hacer login, ¿qué hago?
Asegúrate de ejecutar notebooklm login en una terminal nueva — no dentro de Claude Code ni en la misma ventana. Si sigue sin abrirse, copia la URL que aparece en la terminal y pégala en tu navegador.
Falla la instalación, ¿qué hago?
Dile a Claude Code exactamente qué error ves. Pega el mensaje de error y sigue aceptando — él lo diagnostica y arregla automáticamente. Es su punto fuerte.
Los skills no se reconocen después de instalar
Pregúntale a Claude Code: "¿Puedes verificar que los skills yt-research y notebooklm están instalados y mostrarme cómo usarlos?". Él los recargará si hace falta.
¿NotebookLM tiene límites?
Sí, Google limita cuántos artefactos puedes generar al día (infografías, podcasts, etc.). Si algo falla, espera 5-10 minutos e inténtalo de nuevo. Las búsquedas y resúmenes no tienen límite.
¿Funciona en Windows, Mac y Linux?
Sí. Claude Code está disponible para los tres sistemas. Las instrucciones son idénticas en todos.
¿Mis datos son privados?
Sí. Los vídeos y análisis se procesan entre tu instancia de Claude Code y tu cuenta personal de NotebookLM. Supercursos no almacena ni accede a ninguno de tus datos.
